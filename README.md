# 2026 机场雷达

多来源机场候选与风险档案静态站点。最后整理：**2026-09-26**。

## 当前规模

- **111** 个当前候选名称，来自 4 份公开清单
- **31** 个名称获得至少两份来源交叉收录
- **16** 个名称保留带日期与入口的历史晚高峰样本
- **102** 个风险主体、**121** 条事件，覆盖 2020–2026
- 当前候选与近期风险直接冲突：**流量光**
- 当前候选与历史风险同名：**Fastlink、Bywave、赔钱机场**

> 收录不等于推荐，可达不等于稳定，同名风险也不自动等于当前主体已停运。

## 静态网站

GitHub Pages 部署地址：

**https://yyn666l.github.io/2026-Airport-Recommendations/**

站点支持：

- 名称、协议、线路和标签搜索
- 多来源、历史实测、单一来源与冲突筛选
- 线路筛选和证据/名称/价格排序
- 2020–2026 风险主体、年份和事件范围筛选
- 手机与桌面响应式布局
- 无第三方脚本、无分析追踪、无外部字体

## 数据文件

- [data/catalog.json](data/catalog.json)：111 个候选主体的合并档案
- [data/risk-history.json](data/risk-history.json)：102 个风险主体及事件时间线
- [data/airports.json](data/airports.json)：首批 30 家详细档案，保留兼容
- [data/unavailable.json](data/unavailable.json)：首批 34 条近期风险记录，保留兼容
- [SOURCES.md](SOURCES.md)：来源、时间与判定口径
- [ATTRIBUTION.md](ATTRIBUTION.md)：上游署名与使用说明

## 状态口径

- **多来源收录**：至少两份当前清单都收录该名称，只提高“仍被公开列出”的置信度。
- **单一来源**：仅一份当前清单收录，标记为待复核。
- **含历史实测**：来源提供带时间与测试入口的样本；不能当作今日实时测速。
- **近期来源冲突**：当前清单与 2025–2026 风险来源同时出现。
- **同名历史记录**：当前名称在 2020–2025 历史风险档案中出现，需确认是否同一主体或品牌重启。

## 本地预览

这是零构建依赖的原生静态站点。使用任意静态文件服务器打开仓库根目录即可；不要直接双击 HTML，因为浏览器可能阻止本地 `fetch` JSON。

## 部署

`.github/workflows/pages.yml` 使用 GitHub 官方 Pages Actions，在每次站点或数据文件变更后自动部署。

仓库目前为私有时，GitHub Pages 需要 GitHub Pro、Team 或 Enterprise；GitHub Free 需把仓库设为公开。无论仓库是否私有，Pages 网站本身都会公开访问。
