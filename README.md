## 怎么选，怎么降低损失

1. 首次只买月付或短周期，至少连续观察几个晚高峰，再决定是否续费。
2. 工作或远程协作不要只依赖一家；备用服务应尽量避免共用同一上游。
3. 不在机场面板复用重要账号密码，不公开订阅链接，不安装来源不明的根证书。
4. 先确认常用客户端、设备数量、倍率、流量重置、退款和地区限制。
5. “能打开官网”不等于节点可用，“单次测速很快”也不等于长期稳定。
